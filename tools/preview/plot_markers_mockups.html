Plot Markers

How a plot for sale shows in the world, for admins and players. Today a plot is a yellow box with its id above it, and nothing about it can be changed. These mock-ups add a colour, one of four markers with the plot's name, and settings for size, text size and height.

A marker shows only while the plot is for sale, to everyone nearby. Once it is bought, the marker and the coloured outline go away. A copied plot takes the same look and shows its own new name. The settings below change every scene on this page, so you can compare them.

COLOUR

Four markers pick one or more to build

Each marker stands over the middle of the plot, floats at the height you set (kept inside the plot's own height) and shows the plot's name. Every plot picks one marker, or just the outline.

Where admins set the look three layouts

The same settings in each: the marker, the colour (eight colours and a hex box), marker size, name size, and height above the ground. Players never see these settings; only BSP-Core admins can change them.

After buying the same pop-up as edge travel

When a player buys a plot at a Land Office, or outlines and buys one in an open area, the Land Office closes and this asks whether to go there. TELEPORT puts them on the ground in the middle of the plot, or on its teleport point if the admin set one. STAY, or Esc, does nothing.

Open with them the defaults, also asked in chat

  1. Markers show to everyone while the plot is for sale, and disappear for everyone once it is bought. The owner can still show their own claim with the region key (B), which is now off for players at first.
  2. Open areas get the same look as plots for sale, with the marker over the area's middle.
  3. All four markers are built; each plot picks one (or outline only). Default for new plots: the arrow, in gold.
  4. Sizes from 0.5x to 3x; the height is counted from the plot's floor and kept inside the plot.
  5. Markers show within 96 blocks and are drawn at 20% to 40% opacity; they never hide blocks behind them.
  6. Layout C (the PLOT LOOK window).
  7. After buying: the pop-up above, for Land Office purchases and outlined plots, not for enlarging.
