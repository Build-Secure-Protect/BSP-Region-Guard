REGION SIZE AND CORNERS

Three layouts for B6 and B7 and your three screen requests: the admin screen filling the window with smaller text, a size editor with VERTICAL FILL, corners clicked on the plot map, UNDO/REDO moved off the other cards, and a smaller plot card that folds away.

Each option shows two windows at 960 × 540. In the first, the admin screen is on the INFO tab for market_hall. In the second, the plot map is in corner mode for harbour, a region just made with + NEW and still without corners. The gold tags point at what changed. The fold buttons (▾ / ▸) on the plot cards work.

What all three share (your answers, D71 to D79): corners span the whole world height unless min/max Y are changed, a region without corners shows NO CORNERS YET and protects nothing, and placing corners can be undone.

A · Stretch same layout, more room

The two panes grow to fill the window. The region list shows as many rows as fit, and the tab content is 20% smaller. The INFO tab gets a SIZE block with the six corners as fields. On the plot map, UNDO and REDO join the world card in the top right. The plot card shrinks to three lines and folds to a single strip.

Questions with these mock-ups

  1. Which layout? Default A: it keeps the screen you know, gives the most room, and puts size editing on INFO as you chose (D75).
  2. How much smaller? Default: the admin screen and the plot map's cards drawn at 80% of today's size. The client setting ui.scale still sets the overall size, and the claim screen and the travel pop-up stay as they are.
  3. "The plot modal": I read this as the card beside the picked plot (COPY, UNLOCK, BACKUP) and the toolbar under a moved plot. Default: both get smaller and fold. The PLOTS list card already folds; it gets the same ▸ / ▾ button so all three look alike.
  4. Other regions in corner mode: Default: protected regions and mines show as grey dotted outlines while corners are placed, so you can line up against them. Normally the plot map shows only plots.
