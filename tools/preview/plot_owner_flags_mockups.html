PLOT OWNER FLAGS

Plots get two flag lists: one for visitors and one for owners. Owners then choose what their members may do, within what the admin allows owners.

Why: when the world default denies build, a plot left on inherit takes that deny for everyone, owner included. Setting the plot to allow opens it to every passer-by. With an owners list, the world default only reaches visitors.

Example in every window: market_plot_7 in Sanctuary. The world default denies build, break and place. Bought by Steve, with Alex as a member.

Who reads which list

ADMIN, BYPASS ON

Not stopped by any list, as today.

OWNERS

The OWNERS list. Inherit here means owners may, so the world default never reaches them.

MEMBERS

The MEMBERS list, which the owner sets. A flag the OWNERS list denies is denied for members too, and the owner can't change it.

VISITORS

Everyone else. The VISITORS list, then the parent area, then the world default, as today.

Only flags about what a player does get three values. World events (fire, mobs, explosions, weather) have one value and stay in the VISITORS list.

A. Three tabs in FLAGS VISITORS / OWNERS / MEMBERS above the flag list

Today's FLAGS tab with a switch above it. Each tab is the familiar list with INH / ALLOW / DENY. The hint line says what inherit gives for that tab. The gold BUYER chip on VISITORS replaces the typed "buyer may set" list on the SALE tab.

For

Closest to today's tab. One list at a time, so the rows have room for hints.

Against

To compare visitors with owners for one flag, you switch tabs.

B. One table, three columns every flag shows visitors, owners and members side by side

One row per flag with a value for each group. Click a value to cycle it: INH, ALLOW, DENY. World events show a single wide value. Members' values are the starting values for a new buyer. Steve changes them later.

For

The whole plot is readable at once. Locked member values (dashed) sit right beside the owner deny that locks them.

Against

Denser, and the hint text shrinks to fit. Small windows lose the hints first.

C. A separate OWNERS tab FLAGS stays as today for visitors, OWNERS gets its own tab

FLAGS is unchanged and means visitors. A new OWNERS tab, shown only on plots, claims and open areas, lists the player flags with an owners column and a members column. Settings that are not flags (the buyer list, plot limit) stay on SALE.

For

Protected regions and mines never show owner settings. The visitors list is exactly what admins know.

Against

One more tab in a long tab row. Owner settings are away from the flags they shadow.

What Steve sees the claim card (D24), same in every option

The right side gets two groups. VISITORS shows the flags the admin lets the buyer set, as today. MEMBERS shows every player flag the admin hasn't denied for owners. A denied one shows dashed with "set by the plot".

Questions default in brackets

  1. Which layout? [A, three tabs in FLAGS.]
  2. Which regions get the owners and members lists: plots for sale, claims and open areas. A claim outlined in an open area starts from the area's lists. Protected regions and mines keep one list. [Yes.]
  3. Inherit on the OWNERS list means owners may for the build flags (build, break, place, chests, doors and the rest). For other player flags it means "same as visitors". [Yes.]
  4. MEMBERS: the admin sets starting values. The owner changes any flag the OWNERS list doesn't deny. Inherit on MEMBERS means "same as owners". Members never get more than owners. [Yes.]
  5. VISITORS the buyer may set: a gold BUYER chip per flag replaces the typed list on the SALE tab. The config list stays the default for plots without one. [Yes.]
  6. Which flags get three values: the build flags plus item drop and pickup, ender pearls, chorus fruit, PvP, sleep, ride and the vehicle flags. Fire, mobs, explosions, weather and entry messages stay single. [Yes.]
  7. Copying a plot (D58) copies all three lists and the BUYER chips. A copy is unowned, so the members list is the admin's starting values. [Yes.]
  8. Plots that exist today: their flags become the VISITORS list. Any build-flag deny set on them is also put in the OWNERS list, so no plot opens up by itself. Admins remove it where it was only meant for visitors. [Yes, keep behaviour.]
  9. Commands: /rg flag <region> <flag> <value> [visitors|owners|members], visitors when left out. Owners use /claim flag ... members. [Yes.]
  10. Selling a claim back or a wipe clears the MEMBERS list to the admin's starting values. [Yes.]
