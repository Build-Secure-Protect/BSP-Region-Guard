Other servers on the map: three options

Today the MAP tab's OTHER SERVERS button is all or nothing: every other server's regions in this world appear at once, grey, read-only, labelled "server/id", in the map and in the region list. With four other servers that is a lot of grey. Each option below lets the admin pick which servers show. Example network, all in the Overworld: this server survival-1, and survival-2 (14 regions), resource (6), creative (31), lobby (3). Other servers' regions stay read-only in every option.

A. Server chips one toggle per server, each in its own soft colour

OTHER SERVERS opens a row of chips under the map, one per server with its region count and a colour swatch; click to show or hide that server. ALL and NONE at the end. Each server's regions get their own muted tint (always dashed, so they never look like this server's), and the list on the left follows the same choice.

Good at: comparing two or three servers at a glance; one click per server; the colours tie the map to the chips. Weak at: the chip row grows with the network (two lines at about eight servers); four extra colours on an already colourful map.

B. Drop-down a checklist behind the OTHER SERVERS button

OTHER SERVERS becomes "OTHER SERVERS: 2 of 4 v". Clicking it drops a checklist over the map: each server with its region count and when Region Guard last read it, plus ALL and NONE. The regions stay grey and dashed as today; only which servers appear changes. The choice is remembered until the screen closes.

Good at: the map stays calm (one grey for everyone else); scales to many servers; shows how fresh each server's data is. Weak at: two clicks to change anything; with two servers shown you cannot tell them apart on the map without hovering (the label says the server).

C. Server switcher look at one server at a time, in place of this one

The header gains a server picker with arrows: "SERVER < survival-2 >". Choosing another server swaps the region list and the map to that server's regions in this world, drawn in their normal colours but marked READ-ONLY (no tabs that edit, a gold banner). A small "+ this server" toggle overlays this server's regions in grey for comparison. Back to survival-1 for normal editing.

Good at: reading another server's layout properly (real colours, real list, the INFO tab works); nothing ever crowds. Weak at: one server at a time, so no side-by-side view of three; a mode the admin must remember to leave.
