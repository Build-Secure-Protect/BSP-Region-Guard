Mine Fill

Today a mine's blocks are typed in by name with a weight ("minecraft:iron_ore 8"). These three layouts let you pick blocks from a creative-style browser instead, give each one a percentage in its own box, and show the mine's total at the bottom.

The browser is the one from the BANNED BLOCKS editor: the creative tabs across the top, a search box, and @mod to show one mod's blocks. Only blocks can be added (not items). Type in the percentage boxes in layout B to see the total change.

Open with them defaults, also asked in chat

  1. Layout B, the MINE FILL window.
  2. Shares are percentages with one decimal (0.1% steps), so rare ores like 0.5% diamond work.
  3. SAVE only when the total is exactly 100%; FILL THE REST puts whatever is missing into the filler (the biggest share).
  4. The browser shows blocks only, with the creative tabs, search and @mod, and the blocks already in the mine marked.
  5. Existing mines open with their weights turned into percentages.
